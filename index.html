02

DDSurfer

论文 GitHub

弱监督深度学习 · 大脑皮层三维重建

PythonPyTorchSimpleITKTrimeshFreeSurfer

面向扩散磁共振成像（dMRI）的弱监督大脑皮层重建模型，无需额外 T1w 图像即可生成白质表面和软脑膜表面；第一作者论文发表于 Advanced Science（2026）。

Advanced Science期刊 一区 TOP中科院分区 14.1影响因子
展开技术细节 收起技术细节
  • 职责与协作：主导网络设计、损失函数、训练策略、数据预处理、消融实验和外部数据集泛化评估，并推进核心算法实现与论文实验。
  • 弱监督训练：使用传统方法生成训练伪标签，设计 Unidirectional Boundary Loss 与几何正则约束，缓解噪声标签和复杂皮层边界偏差。
  • 模型架构：设计 Dual-Stream 双分支网络，分别提取各向异性与扩散率特征，经 Cross-SE 跨分支注意力融合；结合多尺度特征、大核注意力和时变速度场（TVF），以微分同胚形变驱动皮层模板网格连续重建。
  • 消融实验：对单分支、移除 Cross-SE、大核注意力及单通道输入进行对照；完整模型相对单分支基线的两类表面 rCoV 分别降低 12.4% / 28.3%。
  • 后处理：构建 FreeSurfer 兼容的表面处理流程，包括网格校验、厚度/曲率/面积计算、脑区分区及标准空间映射；多指标映射步骤由 13.68 秒缩短至 3.23 秒。
  • 性能验证：两类皮层表面的体积相似性由 0.944 / 0.923 提升至 0.985 / 0.980，区域测量离散度降低 25.5% / 31.7%；在 4 个外部数据集（203 名受试者）上，区域一致性指标 rCoV/RSD 显著优于两种对照方法（p < 0.05）。
