StudyHub

study-hub.cn GitHub

校园知识共享平台 · 全栈开发与 AI 应用研发

FastAPINext.jsRAGMCP

主导校园知识共享平台的架构设计、开发与持续运营，覆盖资料共享、经验交流、求购协作与校园集市；将全栈业务系统与知识库 RAG、Agent 工具调用及多模态安全审核整合为 AI 学习平台，并负责平台宣发、用户社群与反馈驱动的迭代。

~400用户 ~2,000下载
展开技术细节 收起技术细节
  • 全栈架构与部署：采用 Next.js（React / TypeScript）、FastAPI、MySQL、Redis、OSS 与独立 Worker 服务，结合 Docker / Nginx 部署，通过权限隔离约束 AI 工具调用与下载授权边界。
  • 知识库 RAG 与增量 Wiki：借鉴 WeKnora，设计 PDF/OCR 解析、结构感知切分与 Parent-Child 分层索引；结合 BM25、向量召回、RRF 与 Rerank 构建混合检索，并通过 Map-Reduce 聚合跨文档知识、增量更新 Wiki，保留文档、Chunk 与页码级引用。
  • Agent 与模型优化：基于 Qwen3.5-9B 与 MCP 实现 ReAct、Plan-and-Execute，结合 vLLM 服务与结构化执行轨迹；开展 LoRA / SFT 与 GRPO 后训练实验，通过可验证奖励、输出约束和 Runtime Guard 优化执行可靠性。
  • 多模态安全审核：基于 Qwen3Guard-Gen-0.6B 与 ShieldGemma 2-4B 设计文本、图像双路审核，引入基于模型 Logits 的 Guard-as-Jev 候选概率评分，结合规则融合、置信度阈值与人工复核进行可解释的风险分级。
02

DDSurfer

论文 GitHub

弱监督深度学习 · 大脑皮层三维重建

PyTorchdMRIWeak Supervision

DDSurfer 通过弱监督双流框架，直接从扩散 MRI 重建白质表面与软脑膜表面，无需额外 T1w 结构像。

Advanced Science期刊 一区 TOP中科院分区 14.1影响因子
展开技术细节 收起技术细节
  • 算法创新：基于 PyTorch 构建双分支网络与跨流特征融合，针对伪标签噪声和边界偏差设计 Unidirectional Boundary Loss 与几何正则约束，结合隐式—显式预测及微分同胚形变，形成从预处理、模板空间推理到原始空间回传的完整流程。
  • 量化效果：相较于初始伪标签，重建皮层区域的影像特征相对离散度（RSD）由 0.550 降至 0.410，降低 25.5%。
