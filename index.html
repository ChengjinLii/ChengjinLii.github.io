StudyHub

study-hub.cn GitHub

校园知识共享平台 · 全栈开发与 AI 应用研发

Next.jsFastAPIMySQLRedisMCPvLLMDocker

主导 StudyHub 的产品架构、核心功能开发与持续运营，服务校园资料共享、经验交流、求购协作及校园集市；在全栈业务基础上拓展 RAG 知识检索、增量 Wiki、Agent 问答与多模态内容审核，并负责权限管理、部署运维和用户反馈迭代。

~400用户 ~2,000下载
展开技术细节 收起技术细节
  • 全栈架构与部署：基于 Next.js（React / TypeScript）、FastAPI、MySQL、Redis、OSS 与独立 Worker 构建前后端服务，通过 Docker / Nginx 部署；围绕资料管理、下载授权和 AI 工具调用设置权限边界。
  • RAG 检索管线、Wiki 知识聚合与更新：参考 WeKnora 的知识库设计，采用 PDF/OCR 解析、结构感知切分和 Parent-Child 分层索引，结合 BM25、BGE-M3 向量召回、RRF 融合与 Qwen3-Reranker-0.6B 重排；以 Map-Reduce 汇聚跨文档实体与概念，通过 Chunk 级抽取缓存、来源追溯和失效知识撤回支持 Wiki 增量更新。SciFact 对照中 Hit@5 由 87.5% 升至 96.9%，MRR@5 由 0.828 升至 0.932。
  • Agent Harness 与模型优化：基于 Qwen3.5-9B、MCP 与 vLLM 搭建 ReAct 多步工具调用框架，并设计面向不同任务复杂度的 ReAct / Plan-and-Execute 执行策略；设计工具调用校验、引用校验与纠错、证据不足处理、上下文压缩及执行预算控制等机制。面向 Tool Calling，基于 LoRA 开展 SFT 与 GRPO 后训练及对照评测，工具调用成功率由 87.5% 升至 93.8%。
  • 多模态安全审核：使用 Qwen3Guard-Gen-0.6B 与 ShieldGemma 2-4B 构建文本、图像及 OCR 图文审核流程；通过候选类别概率评分与默认 0.85 置信度门槛分流，支持高置信度内容按规则自动放行或拒绝，低置信度及争议内容转人工复核。在一组 XSTest 文本离线测试中，自动处理覆盖率为 73.4%。
02

DDSurfer

论文 GitHub

弱监督深度学习 · 大脑皮层三维重建

PythonPyTorchSimpleITKTrimeshFreeSurfer

DDSurfer 是面向扩散磁共振成像（dMRI）的弱监督皮层表面重建模型，无需额外 T1w 结构像即可预测白质表面和软脑膜表面；相关第一作者论文已发表于 Advanced Science（2026）。

Advanced Science期刊 一区 TOP中科院分区 14.1影响因子
展开技术细节 收起技术细节
  • 职责与协作：主导网络架构设计、模型训练、消融实验与跨数据集评估，完成从 dMRI 特征预处理、模板空间推理到原始空间三维网格重建的主要算法开发。
  • 弱监督训练：利用传统图像处理方法生成训练伪标签，并设计 Unidirectional Boundary Loss 与几何正则约束，减轻伪标签噪声和复杂皮层边界偏差。
  • 模型架构：构建 Dual-Stream + Cross-SE 双分支注意力融合网络，结合多尺度特征建模与微分同胚形变，在保持表面拓扑结构的前提下完成三维重建。
  • 性能验证：相较初始伪标签，两类皮层表面的体积相似性从 0.944 / 0.923 提升至 0.985 / 0.980；区域影像测量离散度降低 25.5% / 31.7%，并在 4 个外部数据集（203 名受试者）上评估泛化能力。
03

dMRI-Agent

GitHub

Plan-and-Execute Agent · 医学影像任务编排

PythonLangChainFastAPI3D Slicer

参与研发面向医学影像分析的 Agent 系统，通过自然语言驱动 3D Slicer 执行多步骤数据处理、算法调用与结果分析；将专家工作流封装为 Protocol，以 Planner–Executor 组织任务规划与阶段执行。

展开技术细节 收起技术细节
  • 职责与协作：参与 Agent 架构设计、外部分析工具集成与工作流实验验证，协同完善协议描述、运行约束和交互流程。
  • 任务规划：将专家操作流程封装为结构化 Protocol，借鉴 Agent Skills 的渐进式披露机制，按需加载任务步骤与工具说明，并明确输入输出、阶段检查及异常处置；采用自适应 Planner–Executor 分离全局规划与分阶段执行，根据任务复杂度划分步骤。
  • 工具调用与容错：基于 LangChain、FastAPI 与 3D Slicer 实现受控 Tool Calling、软件模块发现和参数/权限校验；利用阶段 QC、异常恢复与 JSONL 执行轨迹定位失败步骤并追溯执行过程。
  • 效率验证：在 5 类医学图像分析工作流中完成基准任务并复现人工参考结果；与同模型配置下的 Claude Code、Codex、Qwen Code 相比，Token 消耗降低 77.8%–88.5%，LLM 请求次数减少 46.2%–73.9%。
